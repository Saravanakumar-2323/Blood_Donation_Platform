# Blood Donation Platform

## About the Project
The **Blood Donation Platform** is a web-based application designed to connect blood donors with people who need blood. It helps users find potential donors and encourages people to donate blood to save lives.

## Features
- **Home Page:** Provides an overview of the blood donation platform.
- **Donate Blood:** Allows users to explore blood donation information and participate in donation activities.
- **Contact Page:** Helps users contact the platform for inquiries and support.
- **User-Friendly Interface:** Simple and responsive design for easy navigation.
- **Reusable Footer:** Provides consistent navigation and information across the website.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Getting Started

### Prerequisites
A web browser such as Google Chrome or Microsoft Edge.

### Installation
1. Clone this repository:
   ```bash
   git clone https://github.com/Saravanakumar-2323/Blood_Donation_Platform.git
   ```
2. Open the project folder.
3. Open `home.html` in your web browser.
4. Navigate through the website to explore its pages.

## Purpose
The main goal of this project is to create awareness about blood donation and make it easier for people to connect with potential blood donors.
